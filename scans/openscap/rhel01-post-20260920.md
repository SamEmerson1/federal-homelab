## Why the denominator moved

The baseline evaluated 425 rules (167 + 258); this scan evaluated 427 (410 + 17). Four rules
changed applicability, because a rule scoped to a package only evaluates once that package is
installed, and the remediation installed 18 of them:

| Rule | Baseline | Post |
|---|---|---|
| `configure_libreswan_crypto_policy` | N/A | pass |
| `configure_usbguard_auditbackend` | N/A | pass (after remediation) |
| `postfix_prevent_unrestricted_relay` | N/A | pass (after remediation) |
| `package_rng-tools_installed` | fail | N/A (rule applies to physical hardware) |

Both figures are reported here rather than only the score, since a changed denominator affects
any before/after comparison.

## Remaining failures

All 17 are recorded with justification in [`docs/rhel01-remediation.md`](../../docs/rhel01-remediation.md)
and carry into the POA&M.

| Rule | Severity | Reason not remediated |
|---|---|---|
| `installed_OS_is_vendor_supported` | High | Rocky Linux is a RHEL rebuild; the check requires a Red Hat-supported OS |
| `partition_for_home`, `_tmp`, `_var`, `_var_log`, `_var_log_audit` | Low | Single root filesystem; separate partitions require a rebuild |
| `partition_for_var_tmp` | Medium | Same |
| `accounts_authorized_local_users` | Medium | Requires a tailored authorized-user list; documented instead |
| `network_configure_name_resolution` | Medium | Requires two DNS servers; the isolated lab has one domain controller |
| `rsyslog_remote_loghost`, `rsyslog_remote_access_monitoring`, `rsyslog_encrypt_offload_*` (3) | Medium | No log collector yet. The supplied fix points rsyslog at a placeholder host, which would pass the check with nothing behind it. Deferred until Splunk runs on SIEM01 |
| `selinux_context_elevation_for_sudo` | Medium | SELinux role mapping for sudo carries a lockout risk in a single-admin environment |
| `sssd_enable_certmap` | Medium | No PKI or CA in the lab for smart card certificate mapping |
| `fips_custom_stig_sub_policy` | Medium | Conflicts with two other rules in the same benchmark revision; see the remediation notes |
