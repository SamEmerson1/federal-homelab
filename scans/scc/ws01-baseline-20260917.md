## Scope notes

**Profile selection.** MAC-2 Sensitive corresponds to an enterprise system handling sensitive but
unclassified data, which is what WS01 represents. MAC-1 Classified would apply controls with no
remediation path in this environment. The post-remediation scan must use the same profile.

**Manual questions.** The NIWC-enhanced content includes 10 checks requiring human judgment
(organizational policy and physical controls). These were left unanswered and are reported as Not
Checked. The compliance score reflects automated checks only.

**Windows 11 Pro limitation.** Several CAT I failures require Windows 11 Enterprise features that
Pro does not provide:

| Rule | Requirement | Status |
|---|---|---|
| V-253370 | Credential Guard must be running | Not available in Pro — POA&M |
| V-253259 | BitLocker must encrypt all disks | Deferred — lab VM, no TPM-backed key escrow |
| V-253260 | BitLocker PIN for pre-boot authentication | Deferred — same |

These are recorded as risk-accepted POA&M items rather than counted as remediation failures.
